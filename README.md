# 🌍 Geo Safe

## AI-Based Early Warning and Landslide Risk Monitoring System

Geo Safe is an AI-based landslide risk monitoring system designed to provide early warnings for landslide-prone areas in the North Eastern Region (NER).

## 🚨 Problem

Landslides can cause serious damage to people, infrastructure, roads, and the environment. Early detection and timely warnings can help reduce these risks.

## 💡 Our Solution

Geo Safe analyzes important environmental parameters:

- 🌧️ Rainfall
- 🌱 Soil Moisture
- ⛰️ Slope Angle
- 💧 Water Level

The system processes these parameters and generates a **Landslide Risk Score** and **Risk Level**.

## 🤖 AI-Based Risk Analysis

The system uses machine-learning-based analysis to identify potential landslide conditions and support early decision-making.

### Risk Levels

- 🟢 Low Risk
- 🟡 Medium Risk
- 🔴 High Risk

## ⚙️ Main Features

- Real-time parameter input
- Landslide risk calculation
- AI/ML-based analysis
- Risk-level classification
- Early warning support
- Simple web interface
- Future IoT sensor integration
